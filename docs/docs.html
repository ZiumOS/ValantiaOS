01FIRST CONTACT

Try the live system

ValantiaOS Gaming is an experimental Debian GNU/Linux 13 (Trixie) live ISO for AMD64 PCs. Booting the image lets you explore its XFCE desktop without installing it to your disk.

Early software: back up important data and test on hardware you can afford to troubleshoot. Hardware support and gaming performance are not guaranteed. ValantiaOS is not an official Debian release.

Getting an ISO

There is no permanent public release download link. Open the Build ValantiaOS workflow, choose a successful run, then download its ISO artifact and matching SHA256SUMS. GitHub removes artifacts after the workflow's retention period.

Live session account

The current image uses username user, password live, and passwordless sudo. These credentials are for the live session only; never reuse them for an installed or network-facing system.

Booting from USB

  1. Download the ISO artifact and verify its SHA-256 checksum against the accompanying SHA256SUMS.
  2. Write the hybrid ISO to a USB drive with a suitable imaging tool. This erases the selected drive.
  3. Choose the USB device in your computer's boot menu and select a ValantiaOS live entry.
  4. Try your hardware and tools, then report reproducible issues with the workflow run and steps to reproduce.

02BOOT SEQUENCE

What happens at boot?

Firmware starts GRUB, which presents ValantiaOS custom-kernel and Debian fallback live entries. The selected entry loads a kernel and initrd; Debian Live starts the system, then LightDM opens an XFCE session.

The website's animated terminal is a clearly marked illustration of these stages—not output captured from an actual boot.

03FROM SOURCE

Build the ISO

CI builds the hybrid ISO in a privileged Debian Trixie container with live-build. Local builds need Docker, network access, disk space, and permission to run a privileged container.

Build with the project script

From a clone of the repository, run the same build script used by CI:

docker run --privileged --rm \
  -v "$PWD:/work" -w /work \
  debian:trixie \
  bash -euxo pipefail scripts/build-iso.sh

The script creates the GRUB splash, configures live-build, builds the image, and writes the versioned ISO and SHA256SUMS to output/. Read the build script for exact steps.

04KNOWN LIMITS
