Try the live system

ValantiaOS Gaming 0.1.0 is an experimental Debian 13 (Trixie) live ISO for AMD64 PCs. Booting the image lets you explore the XFCE desktop without installing it to your disk.

Early software: back up important data and test on hardware you can afford to troubleshoot. Hardware support and gaming performance are not guaranteed. The project is not an official Debian release.

Getting an ISO

There is no confirmed public release download link yet. When a GitHub Actions workflow run completes, its ISO and checksum are available as workflow artifacts for the configured retention period. Check the repository's Actions page for the latest build.

Live session account

The current live image is configured with the username user and password live, with passwordless sudo. This is for the live environment only; do not reuse these credentials for an installed or network-facing system.

Booting from USB

  1. Download the ISO artifact and verify it against the accompanying SHA256SUMS.
  2. Write the image to a USB drive using a tool that supports hybrid ISO images. This erases the selected drive.
  3. Choose the USB device in your computer's boot menu and select the live option.
  4. Try your hardware and tools, then report reproducible problems through GitHub Issues.

Build from source

The project builds a hybrid ISO with Debian Live's live-build. The GitHub Actions workflow runs the build in a privileged Debian Trixie container; local builds need a Debian-compatible environment and the required privileges.

Install the build tools

sudo apt-get update
sudo apt-get install -y live-build ca-certificates python3-pil fonts-dejavu-core

Configure and build

From the repository root, generate the GRUB splash and run the live-build configuration used by CI:

python3 branding/grub/make-splash.py
lb config \
  --distribution trixie \
  --architectures amd64 \
  --binary-image iso-hybrid \
  --archive-areas "main contrib non-free non-free-firmware" \
  --apt-recommends false
sudo lb build

Builds may need substantial disk space and network access to Debian package repositories. CI uploads the resulting ISO as an artifact; artifact availability depends on workflow status and retention settings.
