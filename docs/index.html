01THE SYSTEM

A live system.
No commitment.

ValantiaOS Gaming is an experimental Debian GNU/Linux 13 (Trixie) live ISO for AMD64 PCs. Boot from removable media to explore an XFCE desktop without installing it to your disk.

It is an independent project in active development—not an official Debian release, and not yet a promise of hardware compatibility or gaming performance.

    07GOOD QUESTIONS

    Before you
    cross over.

    Can I use it without installing? ＋

    Yes. ValantiaOS is a live ISO. Boot from USB to try the environment; writing that USB erases its selected contents.

    Is it ready for daily use? ＋

    No stability or hardware compatibility guarantees. It is an experimental project; avoid relying on it for important work or data.

    How do I verify the download? ＋

    Download the SHA256SUMS file included with the same GitHub Actions artifact and verify the ISO against it before writing the image.

    What is the live login? ＋

    Current live session uses username user, password live, and passwordless sudo. Live-only credentials; do not reuse on an installed or network-facing system.
